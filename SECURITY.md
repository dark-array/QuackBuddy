# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please open a **private** security advisory on GitHub (or email the maintainers)
instead of filing a public issue for vulnerabilities.

Include:

- QuackBuddy version / commit
- OS and desktop environment
- Steps to reproduce
- Impact assessment

We aim to acknowledge reports within 7 days.
